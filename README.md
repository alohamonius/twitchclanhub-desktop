# twitchclanhub desktop

Міні-програма в треї для Windows і macOS: показує алерти й ефекти вашого каналу поверх гри, на вашому екрані.
Працює разом з OBS (він показує ефекти глядачам), а не замість нього.

- Завантажити: [Releases](../../releases/latest): `twitchclanhub-setup.exe` (Windows) або `twitchclanhub-mac.dmg` (macOS, Apple Silicon і Intel).
- Це окремі програми-інсталятори, без магазинів. Збірки поки без підпису: Windows покаже «невідомий видавець» (Докладніше → Все одно запустити), macOS попросить відкрити через правий клік → Відкрити.
- Підключення: у треї «Підключити до каналу», програма покаже код. Введіть його в панелі twitchclanhub у картці «Програма». Ключа OBS програма не бачить: вона отримує власний токен, який видно в панелі й який можна вимкнути там же («Вийти»).
- Підтримка (меню в треї → «Підтримка»): «Очистити кеш» (підключення до каналу лишається), «Скопіювати логи» (версія, система, стан і останні рядки журналу в буфер, без токена й ключів) і «Відкрити папку з логами».
- Гра має бути у віконному режимі без рамки (borderless). У повноекранному (exclusive) Windows ховає будь-який оверлей. На macOS вікно лежить поверх повноекранних програм.

Це оболонка: вікно відкриває сторінку `/screen` вашого каналу. Логіки ефектів тут немає. Токен зберігається в сховищі ОС (DPAPI на Windows) і передається лише заголовком Authorization, ніколи в адресі.

```
npm install && npm start      # запуск
npm test                      # тести розбору посилань
npm run dist:win              # інсталятор Windows (на Windows)
npm run dist:mac              # універсальний DMG (на macOS)
```
