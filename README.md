# twitchclanhub desktop

Міні-програма в треї для Windows і macOS: показує алерти й ефекти вашого каналу поверх гри, на вашому екрані.
Працює разом з OBS (він показує ефекти глядачам), а не замість нього.

- Завантажити: [Releases](../../releases/latest): `twitchclanhub-setup.exe` (Windows) або `twitchclanhub-mac.dmg` (macOS, Apple Silicon і Intel).
- Це окремі програми-інсталятори, без магазинів. Збірки поки без підпису: Windows покаже «невідомий видавець» (Докладніше → Все одно запустити), macOS попросить відкрити через правий клік → Відкрити.
- Підключення: у треї «Підключити до каналу», програма покаже код. Введіть його в панелі twitchclanhub у картці «Програма». Ключа OBS програма не бачить: вона отримує власний токен, який видно в панелі й який можна вимкнути там же («Вийти»).
- Оновлення: на Windows програма сама перевіряє нову версію (при старті й кожні 6 годин) і докачує її, але ставить лише тоді, коли ви оберете в треї «Перезапустити й оновити». Перед цим вона перевіряє наш підпис на завантаженому файлі: версію без підпису або з чужим підписом програма не встановить, навіть якщо хтось підмінить її на GitHub. На macOS поки вручну (автооновлення потребує підпису Apple): пункт у треї веде на сторінку релізів.
- Підтримка (меню в треї → «Підтримка»): «Очистити кеш» (підключення до каналу лишається), «Скопіювати логи» (версія, система, стан і останні рядки журналу в буфер, без токена й ключів) і «Відкрити папку з логами».
- Гра має бути у віконному режимі без рамки (borderless). У повноекранному (exclusive) Windows ховає будь-який оверлей. На macOS вікно лежить поверх повноекранних програм.

Це оболонка: вікно відкриває сторінку `/screen` вашого каналу. Логіки ефектів тут немає. Токен зберігається в сховищі ОС (DPAPI на Windows) і передається лише заголовком Authorization, ніколи в адресі.

```
npm install && npm start      # запуск
npm test                      # тести розбору посилань
npm run dist:win              # інсталятор Windows (на Windows)
npm run dist:mac              # універсальний DMG (на macOS)
npm run icons                 # іконки в assets/ з assets/icon.svg (логотип сайту)
```

## Випуск версії

Ключ підпису живе лише в Keychain засновника на Mac, не на GitHub і не в CI. Його публічна половина вшита в `signature.js`.

1. Підняти `version` у `package.json`, змерджити в `main`, запушити тег `vX.Y.Z`.
2. CI (`release.yml`) збирає інсталятори в **чернетку** релізу. Її не бачать ні програми, ні посилання на сайті.
3. На Mac, у Terminal: `npm run sign-release -- vX.Y.Z`. Скрипт перевіряє, що тег стоїть на коміті з `main`, файли завантажив CI, а хеш збігається з `latest.yml`. Потім підписує інсталятор (macOS попросить пароль: «Allow», не «Always Allow»), додає `twitchclanhub-setup.exe.sig`, публікує реліз і перевіряє підпис за публічним посиланням, як це зробить програма. `--dry-run` лише підписує в тимчасову папку.

Ключ створено один раз командою `npm run release-key`. Його копія має лежати в менеджері паролів (Keychain Access, «twitchclanhub-desktop release key», Show password). Без ключа встановлені програми більше не оновляться самі, лише перевстановленням із сайту. Заміна ключа: новий ключ і старий разом у `RELEASE_KEYS`, один реліз підписаний старим, далі лише новий.
